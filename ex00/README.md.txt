# Personal Portfolio Website

## 1. Project Overview

This project is a personal portfolio website built using HTML, CSS, and JavaScript. It introduces me, presents my technical skills and projects, showcases my hobbies, and provides a contact form.

The website includes interactive features to improve the user experience.

## 2. Technologies Used

- **HTML5:** Structures the webpage and organizes its content into sections.
- **CSS3:** Styles the website, creates layouts, adds hover effects, and supports responsive design.
- **JavaScript:** Adds interactivity by handling user actions and dynamically updating webpage elements.

## 3. Project Structure

```text
ex00/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── profile images and other assets
```

## 4. Website Sections

- **Header and Navigation:** Provides navigation links to the different sections.
- **About Me:** Introduces me and displays my profile photo.
- **Skills:** Presents my technical skills.
- **Projects:** Showcases selected projects.
- **Hobbies:** Displays my personal interests.
- **Contact:** Provides a form for visitors to enter their contact information and message.
- **Footer:** Displays additional information at the bottom of the page.

## 5. Features

- Dark mode and light mode switching.
- Interactive buttons using JavaScript event listeners.
- Hover effects on skill and project cards.
- Responsive layout for different screen sizes.
- Organized webpage structure using semantic HTML elements.

## 6. JavaScript Concepts

- **DOM selection:** Uses `document.getElementById()` to select HTML elements.
- **Event handling:** Uses `addEventListener()` to respond to button clicks.
- **Conditional statements:** Uses `if...else` to control program behavior.
- **DOM manipulation:** Updates webpage elements dynamically.
- **CSS class manipulation:** Uses `classList.toggle()` to switch themes.

## 7. Responsive Design

CSS Flexbox and media queries are used to help the website adapt to different screen sizes, including mobile devices.

## 8. How to Run

1. Download or clone the project.
2. Ensure the HTML, CSS, JavaScript, and asset files are in the correct locations.
3. Open `index.html` in a web browser.
4. Explore the website and test its interactive features.
